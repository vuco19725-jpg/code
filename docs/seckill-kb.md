# 秒杀平台知识库

## 一、秒杀规则

**Q: 秒杀时间是怎么安排的？**
A: 秒杀活动时间由管理员在创建商品时设置，包括开始时间和结束时间。请在商品详情页查看具体时间。

**Q: 每个用户能购买几件？**
A: 每个用户每种秒杀商品限购 1 件，系统会通过 Redis 和 MySQL 双重校验，防止重复购买。

**Q: 秒杀下单后怎么支付？**
A: 秒杀成功后返回订单号，订单状态为"待支付"。目前系统演示版暂不涉及真实支付流程。

**Q: 秒杀成功的订单有有效期吗？**
A: 订单有效期 30 分钟，超时未支付会自动取消，库存会回滚到 Redis。

---

## 二、商品相关

**Q: 怎么查看秒杀商品列表？**
A: 调用 GET /api/v1/goods/list 接口，返回商品名称、价格、库存、开始/结束时间。

**Q: 怎么查看商品详情？**
A: 调用 GET /api/v1/goods/:id 接口，返回商品 ID、名称、价格、实时库存、秒杀时间段。

**Q: 商品库存是怎么管理的？**
A: 管理员创建商品时设置初始库存，活动开始前会预热到 Redis，支持实时查询和扣减。

**Q: 怎么知道商品还有没有库存？**
A: 在商品详情接口可以查看实时库存，秒杀接口也会返回库存状态。

---

## 三、订单相关

**Q: 怎么查询自己的订单？**
A: 调用 GET /api/v1/orders 接口，返回当前用户的订单列表。

**Q: 怎么查询单个订单详情？**
A: 调用 GET /api/v1/orders/:id 接口，返回订单号、商品 ID、订单状态、创建时间。

**Q: 订单状态有哪些？**
A: 订单状态分为三种：0-待支付、1-已支付、2-已取消。

**Q: 秒杀失败会返回什么错误？**
A: 常见错误：已售罄（库存不足）、已购买过（同一用户重复秒杀）、活动未开始/已结束（时间不符）、系统繁忙（熔断触发）。

---

## 四、账户相关

**Q: 怎么注册账号？**
A: 调用 POST /api/v1/user/register 接口，需要提供手机号（11位）和密码（至少6位）。

**Q: 怎么登录？**
A: 调用 POST /api/v1/user/login 接口，使用手机号和密码登录，返回 JWT Token。

**Q: Token 有效期是多久？**
A: Token 有效期 24 小时，过期需要重新登录。

**Q: 支持多设备登录吗？**
A: 不支持，新登录会顶掉旧 Token，同一账号只能在一个设备在线。

**Q: 怎么退出登录？**
A: 调用 POST /api/v1/user/logout 接口，会清除当前 Token。

**Q: 怎么获取自己的用户信息？**
A: 调用 GET /api/v1/user/info 接口，返回用户 ID、手机号、角色。

## 五、系统限制

**Q: 接口有并发限制吗？**
A: 有的，每个用户每分钟限制 10 次秒杀请求，防止刷接口。

**Q: 秒杀接口有超时时间吗？**
A: 有的，秒杀接口超时时间为 3 秒，超过会返回超时错误。

**Q: 什么是熔断器？**
A: 当系统失败率过高时，熔断器会开启"熔断"状态，快速返回"系统繁忙"，保护系统不被压垮。熔断恢复后会自动开放。

**Q: 秒杀失败后库存会怎样？**
A: 如果 Redis 扣库存成功但后续流程失败，系统会自动回滚 Redis 库存，保证库存不错乱。

---

## 六、管理员功能

**Q: 怎么创建秒杀商品？**
A: 使用管理员账号调用 POST /api/v1/admin/goods 接口，设置商品名称、价格、库存、秒杀时间段。

**Q: 怎么修改商品库存？**
A: 使用管理员账号调用 PUT /api/v1/admin/goods/:id/stock 接口。
